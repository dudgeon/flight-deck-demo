How Aviator coordinates and routes work

You asked for the coordination patterns of a Claude Code project's coordinator to be carried into Aviator, and for a way to steer people into the hero skills when they fit without boxing in open-ended work and ideation. This page sets out the patterns first, then seven choices with drawings, including how we would test it and what the director remembers across sessions. Answers save to this page.
